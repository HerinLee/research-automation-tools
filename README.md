# 🧠 Research Automation Tools for Sports Science

This repository documents tools and workflows I’m building to automate data collection, processing, and visualization in human performance research.

---

## 💡 Why?

As a graduate student in exercise physiology, I often found myself spending more time organizing data than analyzing it.  
These tools are my attempt to make research smoother, smarter, and less repetitive.

---

## 🔧 What's in here?

- `notebooks/`: Jupyter notebooks for early prototyping  
- `scripts/`: Clean Python scripts for reproducible workflows  
- `streamlit_app/`: Web-based demo for live data tracking or post-analysis  
- `raw_data_examples/`: Sample data (HR, VO₂, RPE)

---

## 🚧 In progress...

- Recovery curve auto-plotting 📈  
- RPE + HR real-time dashboard with Streamlit  
- Notion + GitHub integration for protocol tracking
